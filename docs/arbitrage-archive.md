# 套利研究归档规范

本文件规定 `reports/arbitrage/` 下的人工研究笔记如何分类、命名和复核。它只描述写作和复核流程。仓库里没有链上监控，也没有程序会在将来自动新增或改写这些笔记。

研究笔记不是交易指令，不构成收益承诺。归档时不执行交易，不加入付费数据源或凭证。

## 目录

```text
docs/arbitrage-archive.md
templates/arbitrage-report.md
reports/arbitrage/README.md
reports/arbitrage/<年份>/<案例短名>/README.md
reports/arbitrage/<年份>/<案例短名>/sources.md
```

- `<年份>` 使用案例所在区块时间的 UTC 公历年。以太坊案例看区块时间戳的 UTC 年，不看归档日，也不改用北京时间的年份。
- 每个案例目录固定放两份文件：`README.md` 是报告，`sources.md` 是来源和证据边界。
- 根目录 [README.md](../README.md) 只保留仓库入口，并链接到 [案例索引](../reports/arbitrage/README.md)。
- 新案例沿用 [模板](../templates/arbitrage-report.md)。不要为了单个案例增加脚本、依赖、凭证或自动写入流程。

## 分类

在索引和报告开头用下面四个字段归类，字段值写短词，不另建多层目录。

| 字段 | 写法 | 本仓库当前例子 |
| --- | --- | --- |
| 链 | 链名称与 chain id | Ethereum mainnet，chain id 1 |
| 策略类型 | 执行边界，而不是营销名称 | 同链、单笔、原子、多池循环 |
| 案例时间 | 区块时间，同时写 UTC 和 Asia/Shanghai | 2025-03-02 17:02:47 UTC |
| 研究状态 | 历史复核、口径待复原、未做现状模拟等事实 | 历史执行已复核；44/24 与 1.58 万美元估值未独立复点；无 2026 年池状态模拟 |

跨链、跨中心化交易所、人工搬砖要另案分类。不能把同链原子交易写成上述类型。

## 命名

案例短名只用小写英文、数字和连字符：

```text
<链简写>-<区块号>-<两个以内的主题词>
```

以太坊简写用 `eth`。主题词描述已复核的结构，例如 `multipool-atomic`。短名不嵌入收益数字、地址或“稳定盈利”之类的判断。

文件名保持 `README.md` 与 `sources.md`。修正已发布数字时，在报告的复核记录里保留旧数字和修正原因，不另建平行目录。

## 报告必须回答的问题

每份 `README.md` 都要能直接找到以下内容。模板里的标题可以保持不变。

1. 结论。
2. 策略类型。
3. 时间和链/区块。
4. 逐步机制。
5. 真实案例。
6. 毛收益、净收益、经营收益的分层。
7. 费用、单位和价格口径。
8. 资金门槛，未知时写未知和未知的原因。
9. 技术架构，范围限于研究理解和只读验证所需的组成部分。
10. 风险。
11. 验证方案和停止条件。
12. 来源。
13. 未解决问题和复核记录。

## 证据等级

报告里的每个关键数字带一个等级。

| 等级 | 含义 |
| --- | --- |
| A | 本次打开的公开页面或公开只读接口上的原始字段 |
| B | 只由 A 级数字做的精确算术，并写明公式 |
| C | 第三方叙述。正文保留其原话范围，未逐项复点 |
| D | 本次没有访问到。写明失败方式，留空，不补造 |
| E | 假设示例，只用于说明符号关系。不能进入案例结论 |

同一数量有多种舍入时，主表使用页面给出的全精度；六位或其他展示精度另列，并写明先舍入再相减，还是先相减再舍入。

## 收益分层

三层必须分开，不能用下一层的缺口去改上一层的原始数字。

| 层 | 内容 | 本归档的最低要求 |
| --- | --- | --- |
| 毛收益 | 交易内部的币种盈余。自动做市商手续费和滑点如果已经体现在成交数量里，就不再扣第二次 | 写清计价币、是否只覆盖其中一条循环、有没有把整笔费用摊进去 |
| 净收益 | 在毛收益上减去本笔能够指认的链上支出，例如构建者直接转账、base fee、优先费和交易 value | 写清每一项付给谁，或者被销毁。优先费为 0 时明确写出 |
| 经营收益 | 净收益再减去研究、节点、失败尝试、资金和其他期间成本 | 没有材料就写“未编制”。不把单笔净额称作经营利润 |

美元列必须指向一个命名的价格字段。浏览器在转账旁边显示的美元，如果对应当次打开页面的现价横幅，就只能作为“现价展示”，不能回填历史收入。

构建者付款是竞价结果，不是协议规定的固定费率。

## 复核规则

1. 写结论前先核对公开区块浏览器中的状态、区块、时间、gas、费用、value、收发地址和关键转账。能取得第二份公开记录时，对照原始字段，不对照双方各自换算的美元。
2. 访问失败就记入 `sources.md` 的 D 级，不改用记忆或估算填上。
3. 第三方统计在独立点数完成前保持 C 级。浏览器的汇总标题如果和第三方统计不一致，两份都保留，并说明页面是否声明列表被截断。
4. 历史回放、最新状态模拟和纸面统计是以后可以做的只读研究步骤。某份报告没有做，就写没有做。
5. 模拟只使用历史状态或单独标明的只读最新状态，不签名、不广播、不提交捆绑交易。
6. 停止条件至少包括：回放结果和收据对不上、价格字段没有名称、样本只剩成功交易、要求把笔记当成当前可执行机会，以及要求把未观察的成本算进经营收益。
7. 每次复核在报告末尾加一行：日期、时区、检查了什么、改了什么、仍然开放的问题。日期使用复核当时的 Asia/Shanghai 日历日。

## 明确不写入仓库的内容

- 私钥、助记词、API key、付费数据源账号和远程签名配置。
- 可广播的原始交易、签名或用于复现交易的完整 calldata。
- 盈利概率、APY、回测夏普、最低本金或其他没有样本定义的业绩数字。
- “机器人正在运行”“监控会自动写入下一份报告”或同等含义的状态。

链上原始数据以公开页面为准。本规范不授权任何人为了补齐 D 级字段去绕过访问限制。
