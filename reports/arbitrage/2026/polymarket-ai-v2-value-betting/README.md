## 2. 原文究竟主张什么

### 2.1 V1 失败并非本研究测得

原文的表格在归档纯文本中连排：做市 V1 为 -1.55，理由“1–2 分价差 < 手续费+滑点”；做市 V2 为 -0.23，理由逆向选择；scalp 为 -0.21；天气 AI 只写“回测负”，理由公开天气数据打不过市场；实盘做市为 -0.30，理由熔断微亏累积。**原文未在可读文本中明确这些数字的单位、资本基数、观察窗、成交量、置信区间，不能解释成百分比或确定 USDC 损失，更不能相加为总亏损。** 这也是对后来“天气稳赚”宣传的重要反证线索，但不足以证明所有天气策略必亏。

### 2.2 V2 主策略：新闻 + LLM + 概率模型

作者称先找信息差/定价偏差，准备 dossier：问题、阈值、现价、剩余时间、24h 动量、恐惧贪婪、新闻标题和盘口赔率。基础模型涉及 S/K/日波动率/剩余天数/正态分布，再按动量和新闻修正；24h 跌幅≥3%、恐惧贪婪≤25、利空新闻≥2 条向下修正，涨幅≥4%及贪婪≥75向上修正。只在 YES 概率≥60%或≤40%时考虑，40%–60%不做；另设 edge 10% 门槛。

必须澄清：**“60%胜率”本身不是优势，60%的东西以70¢买入仍是负期望。** 对某一份 YES，令估计概率为 q、实际买入价 a、每份交易成本 c，则持有到期的模型净期望是 `q-a-c`；NO 用 `1-q` 计算。q 是估计，不是真值。10% edge 的原文公式在 API Article 纯文本中缺失，不能擅自断言是“10个百分点”还是相对比例。

原文说“数学不负责猜方向”，但概率估计、新闻因子及仓位选择都包含方向判断；凯利公式不能把错误概率变成优势。也不应把既有价格作为输入后又声称模型完全独立发现信息。

### 2.3 尾部彩票

触发：24h 跌幅≥1%或恐惧贪婪≤15；筛 BTC 日线、阈值低于现价3%–10%、NO≤15¢、LLM认为 NO 概率高于市场价。每单1.2 USDC，最多两仓；上涨到入场价2.5倍或下跌50%尝试平仓。

这只有在合约问题是“到期价高于 K”时，买 NO 才对应押注到期≤K；若问题方向相反则会买错边。必须按问题和 outcomes 显式映射，不能凭“阈值低于现价”下单。止损是交易指令，不是保证：跳空、薄盘口、API故障时可能不能在 -50% 成交，最多可损失全部彩票本金。两仓同属 BTC 同一到期日时也高度相关。

### 2.4 系统实现与小额限制

作者描述新闻扫描、宏观扫描、crash扫描、value扫描、交易执行和 `reconcile_live.py` 对账，SQLite账本及JSON状态、日志、Windows定时任务；本地面板地址 `127.0.0.1:8787` 是作者电脑的回环服务，**不是公开网站或下载入口，本研究未访问它**。面板有总开关、价差/价值开关和账户同步。

价值单1–2 USDC、最多两仓，彩票单1.2 USDC、最多两仓；建议停做市，出现反证退出、不摊平、亏后暂停。若两模式分别各两仓，同时开启理论本金上限可达6.4 USDC，不能误读成全系统最多两单；实际实现需统一全局上限。

原文自称“市价 BUY 最低1 USDC、金额2位小数，彩票用GTC限价避精度错误，代理钱包常用signature_type=2、部分市场neg_risk=True”。这是待集成测试的实现描述，**不是对所有当前市场适用的官方常量**。GTC不会免除 tick、最小份数或签名检查；小额2 USDC在高价合约上可能达不到盘口 min_order_size。应读每个 market/book 元数据，交易费用也要另预留。

## 3. 对照官方规则：有吻合，也有必须修正之处

### 3.1 BTC阈值盘

本次直接查 [11月20日 BTC above事件](https://gamma-api.polymarket.com/events?slug=bitcoin-above-on-november-20-2026)。规则为 Binance BTC/USDT、ET正午12:00收盘的一分钟K线的最终Close，**严格高于**标题阈值才YES，否则NO。不是任一时刻触价，也不是Coinbase，不可套用5/15分钟涨跌盘的价格源。

因此作者关于币安一分钟收盘的提醒与该样本吻合；“期间不能出现大反弹”不是法律结算条件，只是叙事推理；期间如何波动不影响最终收盘条件。作者把 ET正午恒写成北京时间次日01:00只在美东冬令时成立；夏令时是北京时间次日00:00（即ET日期的下一自然日零点）。应使用 `America/New_York` 时区库，而不是固定UTC偏移；11月样本确为次日01:00。

### 3.2 CLOB V2不是一个永远不变的接口标签

[官方Protocol V2迁移](https://docs.polymarket.com/migrate/polymarket-v2/api-integrations.md)要求按Gamma `version`分流：v2取`positionIds`，v1取JSON字符串`clobTokenIds`；V2使用ExchangeV3及EIP-712 domain version 3，现有CTF路径仍保留domain version 2。当前官方统一SDK及pUSD抵押品命名也与旧教程不同。此次抽样BTC市场仍是`version=v1`；不能因文章写“CLOB V2”就把所有市场按Protocol V2处理。

官方钱包类型区分EOA=0、POLY_PROXY=1、GNOSIS_SAFE=2、DEPOSIT_WALLET=3。2不是所有代理钱包的通用答案。签名者、资金钱包、allowance与exchange、版本、token ID、链ID均应一起校验；不应向聊天提供私钥。官方存在限定范围/期限的session key机制，可在正式设计时评估，不能等同无风险授权。

### 3.3 费用、成本与小本金经济性

核验时现行 Crypto 系数0.07，`fee=C×r×p×(1-p)`，maker平台费0，但有排队不成交和逆向选择。北京时间2026-11-21 07:59起，BTC5/15分钟盘系数0.05，其他Crypto（本案日线阈值类）0.01。必须按成交时间和市场feeSchedule版本计算，不把未来费率回填历史收益。

示意而非实时报价：1.2 USDC以15¢买8份NO，现行单边吃单费0.0714 USDC（约本金5.95%），若q=20%，毛期望0.40，扣该费余0.3286，尚未含LLM/新闻/平仓/滑点。小概率合约的“金额少”不等于相对费率低。若LLM一次分析花0.05美元，100次就是5美元；该数只是成本情景，不是已查询的模型厂商报价。小单很可能是技术验证而非商业化规模。

## 4. 可执行性与bot工程设计

### 4.1 建议架构与时间预算

1. 数据层：Gamma发现市场，固定规则快照；Binance等合规公共数据；新闻源按发布时间去重，记录原文与首次可见时间。约1–3人日。
2. 研究层：模型基础概率、LLM有来源结构化输出、独立校准、Brier/log loss、冲突检查；LLM不直接写入交易队列。约2–5人日初版，证明优势需更长时间。
3. 决策层：实际ask/bid与可成交量、全成本edge、总仓位与相关性限额、事件失效规则；彩票与价值策略账本分开。约2–4人日。
4. 执行层（只有另获授权才进入）：官方SDK、隔离签名器、订单状态机、FOK/FAK/GTC差异、幂等键、撤单与部分成交、最小单/精度/时钟、限流退避。约4–8人日。
5. 运维层：重启恢复、成交去重、余额/持仓/订单三方对账、费用赎回、告警、熔断、灾备。约3–7人日。

上述工作可重叠，是有Python及链上交易经验开发者的粗估，不是可交付承诺；普通人照文章复制并非一键部署。原文归档Article的多处代码块/公式为空，五层结构图也未完整输出；没有源码无法静态审计或复现，不能填补缺失代码冒充作者实现。

### 4.2 自动化边界

- **独立量化脚本：可行。** 新闻事件价值投注通常容忍秒至分钟级，但大新闻套利窗口可能先被专业参与者定价；LLM网络往返/限流/新闻授权延迟可消灭edge。需缓存、增量分析、超时丢弃，不用降低校验换速度。
- **通用AI助手/Grok Bot：只读辅助优先。** 能帮忙归纳新闻、检查合约规则、解释日志和提出概率假设；不是持续运行SLA、确定延迟或安全私钥托管承诺。不能因为帖子写“AI交易”就当作开聊天即可24h赚钱。
- 私钥与资金应由用户在隔离执行环境自管；先审查所在地、账户与API条款，不通过代理或身份伪装绕过地区限制。本研究未验证用户资格。
- LLM输入新闻和网页都是不可信资料，须防提示注入、伪造新闻、过期消息、同源新闻重复计权和模型版本漂移；退出判断同样需要独立定量约束。

## 5. 验证与停止条件

先做无密钥、只读纸面系统，建议至少4–8周，完整冻结预测时刻、当时盘口深度与手续费版本、新闻首次时间、模型版本/输入输出/成本。交易采用延迟后的可成交价及部分成交假设，不用mid和事后最优价。基准包括市场价格、简单波动率模型和不交易；分开统计价值/彩票，按市场日期分组防数据泄漏。

评估概率校准、Brier、扣费净期望、最大回撤、尾部损失和置信区间；100–300个独立结算事件可做初筛但远不足证明小概率尾部盈利，BTC相关事件有效样本更少。压力测试新闻晚到、LLM故障、API429、断网、市场停盘、无法止损和稳定币/平台风险。

预设停止：缺失规则/时间/概率字段、数据过期、模型输出无来源或校准明显劣化立即拒单；模拟净收益不能稳健超过基准、成本大于edge、对账不平、日损失/组合相关敞口超预设预算则停止并复盘，禁止自动加仓补亏。原文2USDC限额仅是单笔约束，不是亏损上限证明。
