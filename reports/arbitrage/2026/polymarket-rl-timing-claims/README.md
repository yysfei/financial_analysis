## 逐步机制

下面是根据作者叙述整理的研究形式。它不是作者实际代码的复原。

1. 在时刻 t 只取当时已经可见的订单簿、成交量、剩余到期时间和价差。事件时间和系统收到时间分开记录。
2. 策略选择交易、持有或退出。作者没有说明方向如何选择，也没有说明份数和订单类型。这些参数是必要的，目前未知。
3. 动作要变成限价单或其他真实订单。排队、部分成交、撤单、拒单和延迟决定实际持仓。
4. 之后卖出，或持有到按该市场规则结算。账本记录现金流和未平仓敞口。
5. 训练和评估使用成本之后的净值变化，以及事先写明的风险目标。不能用未来信息或只存在于模拟器里的标记价格增加奖励。

```mermaid
flowchart LR
  stateNode[当时可见状态]
  actionNode[买或不买或持有或卖]
  fillNode[排队与成交]
  pnlNode[成本后的净值变化]
  stateNode --> actionNode
  actionNode --> fillNode
  fillNode --> pnlNode
```

上图是研究时的抽象顺序，不是已经部署的代理。

代理即使不直接读取新闻，也可能从别人的交易、相关市场或价格路径里间接形成预测。“没有情绪”不消除模型错误。成交量峰值如果只有事后才能知道，就不能把这个峰值放进决策时的输入。四个输入之间可以重复，输入个数本身不表示方法更先进。只奖励赚钱，可能鼓励加仓、频繁交易、押注极端结果或利用模拟器漏洞，所以动作边界和风险约束必须单独检查。

### 胜率不能推出期望收益

盈亏幅度不同时，67% 的胜率不能决定期望。设平均盈利为 A、平均亏损为 B，再减去成本：

```text
单位交易期望 = 0.67A − 0.33B − 成本
```

没有 A、B、成交次数、赔率、敞口和回撤，就不能判断有没有优势。二元市场上大量买入高价、低赔率的结果，可以提高命中率，同时把亏损留在少数尾部。需要按价格分组的净收益分布，而不是只报命中率。

### 夏普 2.3 还没有口径

需要固定的采样间隔、是否包含闲置现金、无风险基准、窗口、年化系数、交易之间是否相关，以及训练时试过多少模型。逐笔、持有时间不同的收益，不能直接和日净值夏普比较。短样本和多次调参后留下的最佳模型会有选择偏差。本报告不补一个年化夏普。

### 48¢ 到 96¢ 的算术

如果以 0.48 买入、以 0.96 卖出，未计费用时每份赚 0.48。利润 1,200 美元对应 2,500 份，买入价款也是 1,200 美元。这只是满足作者利润所需的名义规模，不是实际成交量。

普通胜方的最终赎回通常是每份 1 美元，不是 0.96 美元。若这 2,500 份最后按 1 美元兑付，未计费用的毛利润是 1,300 美元，而不是 1,200 美元。0.96 更适合先写成可能的卖出或退出价。差额可以来自费用、不同份数或其他交易。这里要求原始记录，不把差额裁定成虚假，也不替作者补上一种结算。

“作者在 52¢ 犹豫、代理在 48¢ 早 6 小时”还需要同一信息时点、当时的盘口、相同本金和相同风险约束，并核对 48¢ 是否能成交所需份数。

11/14 的样本很小，比较对象也不稳定，市场结果不一定相互独立。本人不是唯一基准。至少还要和不交易、固定风险仓位、简单动量或均值回归、以及只按到期和价差行动的规则比较。11/14 不能外推成长期胜率。

## 收益分层

```text
期末净资产 = 可用抵押品 + 按可执行平仓价计算的持仓价值
期间净损益 = 期末净资产 − 期初净资产 − 外部净注资
```

现金余额里已经计入的成交费用、gas、返佣，不再从净资产差额里重复扣减或相加。单笔若分项计算：

```text
Π_i = 卖出或赎回回收
    − 买入价款
    − 尚未包含在价款里的交易费
    − 自付链上费用和兑换、转移成本
    + 实际获得且尚未计入回收的返佣或奖励
```

买入和卖出的 VWAP 已经反映价差和冲击，不再另扣同一次价差或滑点。未平仓按保守的可执行价格估值；结束时要么强制按可执行价格了结，要么把剩余风险单独列出。不能只结算盈利的单子，把亏损浮仓留在账外。平台展示的总收益如果已经含费或含返佣，不能再把各类收入加一次。资金占用另列，不把年化数字写成已经收到的利息。

## 风险

方向敞口、持仓集中、突发消息、规则读错、预言机争议、临近到期无法退出、平台和抵押品风险，都会留在这种择时里。历史价格不等于当时的完整订单簿和队列。短纸面样本和多次调参会抬高看起来最好的那一次。胜率高而赔率低时，亏损可以集中在少数交易。费用和返佣随类别、日期改变；缺市场 ID 时使用任何单一费率都会算错。推荐链接不构成欺诈证据，但成绩宣传和推广放在同一帖里，更需要独立账本。

## 验证方案与停止条件

本次只核对了帖文主张的边界，以及官方费率、返佣和结算规则。没有运行模型，没有训练，没有全量回测，也没有做前瞻纸面观察。

以后的纸面验证按这个顺序：

1. 先冻结方向、份数、订单类型、风险限制、特征、奖励、超参数、训练区间和种子。作者没披露的部分标成自建研究。
2. 只用决策当时可得的数据。去掉未来窗口、事后峰值、结算标签、事后修订和未来新闻。
3. 训练、验证和最终测试按时间前推。重叠到期的事件做隔离，避免相关市场污染。
4. 撮合记录队列和部分成交。不能成交就不计收益。再改延迟、深度和费率，看结果是否还在。
5. 与简单规则比较。报告多种子分布、回撤、平均盈亏、容量、敞口、换手、库存尾部和成本。夏普只按固定频率的净值收益报告，并给出不确定性。
6. 冻结后再做前瞻纸面。观察期和停止条件事先写下来，保留全部候选和失败订单。
7. 若要核验作者本人的成绩，需要可公开的市场 ID、逐笔纸面订单和成交假设、时间戳、钱包与结算哈希、样本外预测、初始本金和全成本净值。没有这些材料，就不写“已经验证作者模型”。

停止继续升级的条件：决策使用了未来信息；最终测试被反复拿来调参；结果无法重现；净收益只在乐观成交假设下为正；加上成本后优势消失；收益集中在少数事件；合规资格不能确定；没有账本或净值基数却要发布收益率。任何人要求把本笔记当成已运行的代理或当前下单信号，也停止。
