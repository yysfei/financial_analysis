## 结论

[@linda6248130564](https://x.com/linda6248130564/status/2125119598437818481) 宣传一个冷门天气账户赚到 48,031 美元，做了 4,739 次预测，单笔 500–2,000 美元，只盯达拉斯、休斯顿、迈阿密、丹佛和墨西哥城，方法是核对天气预报、抓市场共识偏差。帖中还给出三笔结果：$2 到 $970.96、约 485 倍；$785.15 到 $2,337.70、+198%；$621.51 到 $1,897.27、+205%。

本轮打开 <https://polymarket.com/ja/@neo7777>（`via=k3H86f8` 不改变身份）。页面字段为：Joined Jan 2026，6.2K views，Positions Value $0.00，Biggest Win $3,735.32，Markets Traded 7,958，Total PnL +$47.9K，Total Volume 4.7M。可见市场是各城市最高气温档。城市比宣传更广，页面上还能看到洛杉矶、纽约、卡拉奇、吉隆坡、马德里、台北、青岛、华沙、圣保罗等。这份名单是打开时看得到的例子，不是完整持仓清单。

**可以核对的是累计盈亏的数量级。** 页面显示 +$47.9K，与 48,031 美元同一量级。页面不是精确到个位的 48031，本笔记不把 +$47.9K 改写成 48,031。

**不能直接核对的有三项。** 4,739 次预测和页面上 7,958 个交易过的市场不是同一口径，不能等同。单笔 500–2,000 美元与页面上既有约 0.4 份、也有上千份的持仓规模不完全一致。三笔亮眼结果本轮没有在公开页上定位，记为 C/D。用宣传数字做除法，只能检查作者自己的算术：970.96 / 2 = 485.48，和「约 485 倍」接近；(2337.70 − 785.15) / 785.15 ≈ 197.7%，接近所写的 +198%；(1897.27 − 621.51) / 621.51 ≈ 205.3%，接近所写的 +205%。这些除法不证明成交存在。

这不是已验证的可复制系统。没有模型名单，没有概率公式，没有最低 edge，也没有仓位公式。同线程有 `via=k3H86f8` 和跟单机器人引流。不能自动下单，也不应连接钱包。

## 策略类型与适用环境

- 属于：用天气预报对照城市最高气温档的市场价格，寻找共识偏差。这是方向性价值投注。
- 适用环境（按宣传，规则并未写完）：预报和官方结算站口径一致，偏差在费用之后仍为正，并且只在作者点名的城市里出现。公开页显示城市范围更广，所以「只盯五座城市」至少不是这个钱包的全部可见市场。
- 不属于：无风险套利，也不属于另一篇里的 Open-Meteo 八模型、平滑概率和 0.08 edge。那一套有公式，这一套没有。

## 盈利来源与成立条件

若按原文理解，盈利来自气温档价格相对预报的偏差。成立条件包括：预报变量等于结算变量，档位边界读对，下单价格仍保留偏差，相关城市不被当成独立样本重复加仓，以及公开盈亏确实来自这些偏差而不是别的市场。

本轮只能支持弱得多的说法：这个用户名下的公开页以气温档为主，累计盈亏显示约 +4.8 万美元。它不能支持「按 500–2,000 美元、只做五座城市、稳定抓到数倍单」已经可以被复制。

## 收益口径与完整成本

可写进对照的只有打开时的累计显示 +$47.9K，以及它和宣传 48,031 美元处于同一显示量级。最大单笔赢利显示 $3,735.32。这与宣传里 $2 变成 $970.96 的例子不是同一笔的证明，因为那一笔没有在页面上定位。$970.96 也低于页面上的最大单笔显示，所以它即使存在，也不是页面标出的最大赢利。

4,739 和 7,958 不能相减之后当成「隐藏了 3,219 个市场」。两者标签不同。Positions Value $0.00 是当前持仓价值字段，不是累计盈亏。

完整成本未披露：点差、未成交、预报和气象站不一致、同一天气系统下多城市相关。本笔记不编造费率，也不把三笔倍数年化。

## 风险

- 复制风险：没有公式和阈值，换一个人会得到不同的「共识偏差」。
- 结算风险：预报网格和官方气象站可以不一致。另一篇天气笔记已经把这件事写成作者自己踩过的坑，本钱包没有展示如何处理。
- 相关性：多座城市在同一天气系统里同涨同跌。五座或更多城市不是五个独立样本。
- 样本与宣传不一致：城市更多、市场数和预测次数对不上、持仓份额宽于 500–2,000 美元。
- 路径风险：气温档可以归零。三笔高倍例子若属实，也不能代表其余几千次。
- 利益冲突：邀请参数和跟单机器人与盈利故事放在一起。

## 可执行性与自动化部署评估

- 开发难度：只读打开这个钱包页即可核对累计盈亏的数量级。要复现策略，缺少模型、偏差定义和仓位。这些不是从 7,958 个市场数可以反推的。
- 能否确定性自动化：不能。没有 edge 公式，城市名单与页面不符，三笔例子也未定位。
- AI / Grok Bot 的边界：可以在有人监督时阅读公开页、列出气温档，并标明哪些宣传数字对得上。不能连接钱包，不能按「共识偏差」自动下单，不能把 +$47.9K 写成这套未写完规则的利润。
- 不适合自动化的原因：规则不完整，样本口径不一致，天气档之间相关。原因不是因为相邻笔记已经讨论过天气就可以跳过。
