## 结论

[@chenke20266](https://x.com/chenke20266/status/2124862228486840567) 的文章《我用GROKBOT在 Polymarket做天气市场：从０到１可复刻的交易系统》把一套天气档位规则写了出来：8 个数值模式落入区间的比例，经平滑后当作概率，和市场价格相差至少 0.08 才用 1 USDC 买 YES 或 NO。规则公开，逻辑可以讨论。

一天纸面 72 笔不是已验证盈利。作者自己写的是 11/23 结算批次、样本只有一天，并写明供学习交流、不保证效果。宣传钱包 shamubronze3 真实存在，官方页累计盈亏为正，这不能证明上述公式，也不能证明扣费之后还有可复制的净利。作者一天纸面 +10.35 USDC 和该钱包的官方累计盈亏必须分开写。

这不是套利。可做只读纸面复现，因为 Open-Meteo 与 Gamma API 都是公开接口；本轮没有实际跑这套复现。Grok Bot 不应连接钱包或自动下单。文章虽称有 `weather_live_bot.py` 和审批锁，本轮未见公开源码，不能当成已审计的安全实盘框架。

## 策略类型与适用环境

- 属于：慢频的方向性价值投注。估计概率来自多个天气预报模型的分档计数，交易决定是这个概率和市场价的差。
- 适用环境：有人能读官方结算规则、能把纸面结果和 `outcomePrices` 对上，并且接受同一天多座城市高度相关。
- 不属于：YES 与 NO 合成后赎回的完整集合，不属于邻档口诀，不属于高价买 NO 的那一套账户，也不属于五分钟 BTC 的延迟交易。

作者开篇称，看了 <https://polymarket.com/zh/@shamubronze3?tab=activity> 之后用 AI 逆向思路，并称「一个月盈利 $10229」。这是作者的话，等级 C。官方页怎么读，见下文单独一节，不把这句话直接升成事实。

## 作者写下的规则

下面全部是作者文本，等级 C。公式按文章抄写。本轮没有把它改写成文章未给出的推广式，也没有另做参数搜索。

标的是 Polymarket 城市最高气温档位。例子是 “Highest temperature in Beijing on November 23?”。

数据是 Open-Meteo 的 8 个模型：ECMWF IFS025、GFS、ICON、JMA、GEM、UKMO、MeteoFrance ARPEGE、BOM ACCESS。

档位概率有两种写法。平滑公式是 P = (k + 0.5) / (N + 1)。文中也写过不平滑的「落入区间的模型数 / 总模型数」。代码示例是：

```python
def bucket_prob(values, lo, hi): k = sum(1 for v in values if lo <= v < hi); return (k + 0.5) / (len(values) + 1)
```

edge = P − 市场价。edge≥0.08 买 YES（1 USDC）。edge≤−0.08 买 NO（1 USDC）。NO 价格按 1 − YES 价。

风控：每笔 1 USDC，最多 5 个持仓，总敞口 ≤ 5 USDC，单日亏损 ≥ 3 USDC 停止。不用凯利，理由是样本小。

执行：Polymarket CLOB 的 GTC 限价单。

作者自称纸面，对应 11/23 结算批次、一天：已结算 72 笔，39 胜 / 33 负 = 54%，纸面盈亏 +10.35 USDC（每笔 1 USDC）。并对比：之前做市 13 笔 0 胜 −0.30；5 分钟 BTC 延迟套利 6 信号 0 胜 −6.00。在接受作者所写笔数的前提下，39/72 与 54% 的除法相符，这只是 B 级算术，笔数本身仍是 C。作者写明样本只有一天，需再跑 2–4 周。结论里说再跑 2 周纸面，若保持正期望再用 1 USDC/笔小仓实盘。这里的周数是作者自己的计划，不是本笔记估计的工期。

作者列出踩过的坑：

1. 用 Open-Meteo 实际温度结算，与官方比 12 笔错 4 笔，因为官方用指定气象站而不是网格值。必须以官方 `outcomePrices` 结算。
2. 假 edge。模型 80% 对市场 12% 常常是口径差异，需要 Brier 校准。
3. 市价最小 1 USDC、精度 2 位。作者改用 GTC，并向上取整。
4. 5 分钟 BTC 延迟套利（文中称 Vega7 / Chainlink TWAP）复制不了。作者认为天气更适合中频价值投注。

风险也是作者写下的：模型集体出错；结算源差异导致纸面虚高；72 笔不够；流动性差、大单滑点；同一天多城、多档高度相关。

代码只列了本机路径，包括 `weather_paper_bot.py`、`weather_live_bot.py` 等。没有给出可克隆的公开仓库。

免责声明写的是个人研究，不构成投资建议，可能损失全部本金。文章还说 AI 纸面胜率 54%，供学习交流，不保证效果。

## 风险

- 模型会一起错。8 个模式不是 8 个独立的天气。
- 结算源不同会让纸面虚高。作者已经写了 12 笔里 4 笔和官方不一致。未改用 `outcomePrices` 之前，纸面盈亏不能当成绩。
- 72 笔、一天，不够支撑正期望。作者自己也要求再看更长的纸面。
- 流动性差时，1 USDC 的纸面 edge 到不了更大的单。
- 同一天多城、多档相关。5 个持仓可以是同一天气系统的重复暴露，总敞口 ≤ 5 USDC 只是名义上限。
- 推广帖把群内实盘和 token 费放在一起。这是利益冲突，不是业绩。
- 旧文里的天气 AI 回测为负还在。新规则没有把它证伪。
